        What do these controls mean?
        
The camera describes every pixel using three properties. A pixel is accepted only when
          all three settings match. The mask preview highlights accepted pixels.

        

          
Hue bands — which colour?

          
These select the red part of the colour wheel. Red sits at both ends of the wheel,
            so two bands are needed: usually one near 0 and one near 180. Wider bands accept more
            shades, but can also accept orange, pink, or purple objects.

          
Minimum saturation — how colourful?

          
Raise it to reject white, grey, and washed-out areas. Lower it if pale parts of the
            marker are missing.

          
Minimum brightness — how light?

          
Lower it to include the marker in shadow. Raise it to reject dark red or brown
            background objects.

        

        
Good result: the whole marker is highlighted and the surroundings stay
          dark. Make small changes, refresh the preview, and apply only after checking it.
